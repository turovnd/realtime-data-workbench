# Historical archive

These are preserved earlier research notes, scenario plans, style checkpoints and implementation records. They are not current setup instructions or current authorization. Their original statements and dates are retained, including superseded assumptions; they do not prove that proposed work was implemented.

All original files are retained under initial-delivery/. The preservation-sha256.json manifest records the archived bytes; no historical authorship or development timeline is invented. Historical relative links may point to old paths. The main [documentation index](../README.md), [delivery ledger](../delivery-status.md) and [current plan](../../planning/README.md) supersede these records for current behavior.
